# یاران — مهدکودک و پیش‌دبستانی مجازی

تور مجازی تعاملی مهدکودک با ۱۳ اتاق، ۸ بازی آموزشی، ۸۳۴ کاربرگ، سیستم گزارش‌دهی روزانه، تخته پیگیری وظایف، و ربات تلگرام همگام.

## 🚀 شروع سریع (لوکال)

```bash
# کل پروژه (سایت + سرور API + ربات تلگرام) با یک فرمان:
cd server
npm install
npm start
# سایت: http://localhost:4000
# API: http://localhost:4000/api
# WebSocket: ws://localhost:4000/ws
```

### فقط سایت (استاتیک)
```bash
npx serve .
```

### فقط ربات (با .env لوکال)
```bash
cd telegram-bot
npm install
node bot.js
```

## 🌍 استقرار رایگان

راهنمای کامل قدم‌به‌قدم: **[DEPLOYMENT.md](DEPLOYMENT.md)**
- سایت → GitHub Pages (`site-live` branch)
- سرور + ربات → Render (free)
- بدون Firebase، بدون دیتابیس — همه‌چیز فایل JSON

## 🔧 تنظیمات

| فایل | نقش |
|------|-----|
| `telegram-bot/.env` | توکن ربات، ADMIN_ID، پروکسی (در گیت نیست — نمونه: `.env.example`) |
| `js/config.js` | آدرس سرور API برای GitHub Pages (`window.YARAN_API_BASE`) |
| `server/start-all.js` | اجرای سرور + ربات در یک پروسه (برای Render) |

## ✨ امکانات

### 🏠 تور مجازی
- **۱۳ اتاق تعاملی** با تور ۴ نمایه (جلو، چپ، راست، گوشه)
- **۸ بازی آموزشی** (حافظه، سایمون، الگو، پازل و...)
- **۸۳۴ کاربرگ** قابل چاپ
- **نکات روزانه فرزندپروری**
- **نقشه تعاملی** اتاق‌ها با دایره‌های نعل‌اسبی

### 📋 پنل کاربری
- **برنامه‌ریز هفتگی مهد** — جدول ۷ روزه با ساعت‌بندی
- **انتخابگر محتوا** — جستجو و اضافه کردن محتوا به خانه‌های برنامه
- **تقویم شمسی** با جلسات و رویدادها
- **سیستم گزارش‌دهی** (خوراک، خواب، احساسات)
- **تخته پیگیری وظایف**
- **ارتباط با والدین** — پیام با ضمیمه محتوا

### 🔍 جستجو و طبقه‌بندی
- **فیلترهای taxonomy** — نوع، حوزه رشد، مخاطب، ژانر
- **۱۰+ فیلد طبقه‌بندی** — شناختی، زبان، هنر، موسیقی و...
- **جستجوی یکپارچه** — کاربرگ، ویدیو، صوت، بازی، فعالیت

### 👥 نقش‌ها
- **مدیر** — دسترسی کامل به پنل و تنظیمات
- **مربی** — برنامه‌ریزی، گزارش، ارتباط با والدین
- **والد** — مشاهده برنامه، تأیید/رد جلسات، پیام‌ها
- **کودک** — فقط تور مجازی و محتوای صوتی

### 🤖 ربات تلگرام
- **همگام با سایت** — وظایف، پیام‌ها، رویدادها
- **ارسال محتوا** — ضمیمه کاربرگ، ویدیو، صوت
- **خودکار** — keep-alive هر ۱۰ دقیقه

### 🎨 طراحی
- **طراحی واکنش‌گرا** (موبایل + دسکتاپ)
- **پوسته روز/شب/جشن**
- **RTL کامل** — فارسی از راست به چپ
- **فونت Vazirmatn** — حرفه‌ای و خوانا

## 🔒 امنیت

- CSP header فعال
- XSS protection روی محتوای کاربر
- Rate limiting روی فرم‌ها
- JWT auth با bcrypt
- حذف نقش admin از فرم ثبت‌نام
- توکن ربات فقط در `.env` (در گیت نیست)
