# Yaran Telegram Bot — مدیریت وظایف مهدکودک
# منوی شیشه‌ای + مدیریت وظایف روزانه گروه

## ویژگی‌ها
- 📋 مدیریت وظایف با دکمه‌های شیشه‌ای
- 📊 گزارش روزانه خودکار
- 👥 تخصیص وظیفه به مربیان
- ⏰ یادآوری خودکار
- 📈 آمار عملکرد تیم

## نصب
```bash
cd telegram-bot
npm install
cp .env.example .env   # توکن ربات رو تنظیم کن
npm start
```

## تنظیم ربات
1. با @BotFather ربات بسازید
2. `/setcommands` رو بزنید و کپی کنید:
```
start - شروع و خوش‌آمدگویی
tasks - مدیریت وظایف
addtask - افزودن وظیفه جدید
mytasks - وظایف من
report - گزارش روزانه
help - راهنما
```
3. توکن رو در `.env` قرار دهید
4. `npm start` کنید
5. ربات رو به گروه مهد اضافه کنید
