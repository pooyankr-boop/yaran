# گزارش ارتقای یاران ۲ (UPGRADE NOTES)

فهرست کامل کارهای انجام‌شده در بازسازی `old/yaran` → نسخه‌ی ارتقایافته.

---

## ۱) تایپوگرافی فارسی و سیستم طراحی

- **۵ خانواده فونت بومی (woff2، کاملاً آفلاین)** در `assets/fonts/`:
  - Vazirmatn (متغیر) — بدنه
  - Lalezar — تیترهای نمایشی شاد
  - Estedad (متغیر) — رابط و دکمه‌ها
  - Markazi Text — زیرتیتر سردبیری
  - Amiri 400/700 — قصه و نقل‌قول
- `css/design-system.css`: توکن‌های CSS برای هر سه تم (روز/شب/جشن) به‌جای رنگ‌های هاردکد؛ کلاس‌های متن زنده: `.yr-wavy`, `.yr-hopping`, `.yr-glow`, `.yr-underline` (خط رنگین‌کمانی خودکش), دکمه‌های اسپرینگی `.svgx-fab`, اسکرول‌بار شاد.
- صفحه‌ی اینترو: ماسکوت متحرک + عنوان موج‌دار + CTA پالس‌دار.

## ۲) تقویم شمسی (Jalali) سراسری

- `js/jalali.js` — الگوریتم استاندارد jalaali با تست رفت‌وبرگشت کامل ۱۹۰۰–۲۱۰۰ میلادی (بدون خطا)، نام ماه/روز، ارقام فارسی، شبکه‌ی ماه، زمان نسبی فارسی.
- جایگزینی همه‌ی تاریخ‌های نمایشی:
  - گزارش‌های روزانه کودکان (app.js) → «پنج‌شنبه ۴ شهریور ۱۴۰۵ — ۱۴:۳۰»
  - ساعت لابی (`getIranDateTime`) → شمسی قطعی مستقل از مرورگر
  - پیام‌ها → «۳ دقیقه پیش» فارسی
  - برنامه‌ریز → تقویم کامل جلالی

## ۳) دسته‌بندی محتوا — بازطراحی از صفر

- `js/taxonomy.js` — سامانه فاستی **YaranTax**:
  - **type**: worksheet / video / audio / game / activity / deck / form
  - **domain**: شناخت، زبان، ریاضی، علوم، حرکت، اجتماعی-عاطفی، هنر، موسیقی، زندگی، سلامت، خانواده، حرفه‌ای
  - **audience**: کودک / والدین / مربیان / مدیران
  - **age**: ۲–۳ … ۵–۶ / همه
  - **genre**: قصه، لالایی، ترانه، مدیتیشن، پادکست، شعر، آرامش، آموزشی
- نگاشت صریح **۱۸۸ دسته‌ی قدیمی** + ۱۶ قاعده‌ی احتمالی روی عنوان/توضیح.
- تست روی داده واقعی: ۱۴۹۸ آیتم، صفر خطا، ۱۰۰٪ پوشش نوع و حوزه.
- یکپارچه در: جستجو (نوار فاست چندانتخابی)، بایگانی، محتوای اتاق (چیپ نوع+ژانر بر اساس محتوای واقعی همان اتاق)، کارت‌های نتیجه.

## ۴) SVG متحرک همه‌جا

- `js/svgx.js` + `css/svg.css`:
  - ماسکوت «یاربر» با نفس‌کشیدن/پلک‌زدن/دست‌تکان‌دادن
  - ۳ لودر (بلوک‌های پرنده، بادی‌پین‌ول، ستاره‌های مداری)
  - حالت خالی داستانی (ابر بارانی که آفتاب پیدا می‌کند / بادکنک)
  - **دکور اختصاصی هر ۱۳ اتاق + لابی/پلان/نقشه**: ریسه پرچم، بادکنک، خورشید چرخان، ابر شناور، پروانه بال‌زن، نت‌های موسیقی، مکعب‌ها، گلدان، ستاره‌ها، موشک، رنگین‌کمان، قلب تپنده…
  - ذرات تم‌محور: حباب (روز)، ستاره چشمک‌زن (شب)، کاغذرنگی (جشن)

## ۵) درس تعاملی والدین/مربیان (اسلاید‌دک)

- موتور `js/decks.js`: ۹ نوع اسلاید (عنوان، متن، آزمون، سناریو، برگردان، مرتب‌سازی ترتیبی، مقیاس خودارزیابی، چک‌لیست، نقل‌قول)، نوار پیشرفت رنگین‌کمانی، سوایپ/کیبورد، امتیاز و ستاره پایان.
- محتوا `deck-data.js` — ۱۰ دوره واقعی فارسی:
  - والدین: خداحافظی بی‌اشک، بدغذاها، صفحه‌نمایش، قشقایی، آمادگی مدرسه، خواب مستقل
  - مربیان/کارکنان: گفت‌وگو با والدین، مدیریت کلاس، ایمنی مهد، مشاهده رشد، کمک‌های اولیه
- تزریق خودکار به اتاق‌های مربوط (جلسه اولیا/مربی/استراحت/تریا) + دکمه‌ی «مشاوره و آموزش» در لابی + قابل فیلتر در جستجو.

## ۶) بازی‌های جدید کودکان (`games3.js`)

۶ بازی SVG با سطح‌بندی خودکار: سایه‌ی کیست؟ · باغچه‌ی شمارش · حباب‌های الفبا · بزرگ یا کوچک؟ · جادوی رنگ · هیولای گرسنه. ثبت در همان رجیستری مشترک GAMES (مجموعاً ۲۷ بازی).

## ۷) پنل برنامه‌ریزی و ارتباط با والدین

- فرانت `js/planner.js` + `css/planner.css`:
  - تقویم ماهانه شمسی با مناسبت‌ها، ناوبری ماه، انتخاب روز
  - ساخت جلسه/رویداد/یادآور (نوع، ساعت، مدت، والد، کودک، یادداشت)
  - پیام به والدین: تک‌والد یا اعلامیه همگانی + **ضمیمه از کتابخانه‌ی محتوا** (انتخابگر با جستجو/فیلتر نوع، تا ۸ ضمیمه)
  - نمای والدین: جلسات پیش‌رو با دکمه‌های «می‌آیم/نمی‌توانم» + صندوق پیام دریافتی با کارت ضمیمه‌های قابل باز شدن
- سرور `server/planner.js`: `GET/POST/PATCH/DELETE /api/planner/events`، `GET /api/planner/parents`، `GET/POST /api/parent-messages` — با کنترل نقش (والد فقط رویدادهای خودش و فقط تغییر وضعیت).
- ذخیره: `data/planner.json`.

## ۸) خط تولید رسانه (workflow تصاویر Gemini)

- `docs/media-generation-prompts.md` — کتاب پرامپت کامل: استایل پایه + ممنوعه‌ها + حال‌وهوای هر اتاق + پرامپت اختصاصی برای ۸۶ تصویر (۱۳ اتاق × ۶ نما + لابی + پلان) + ویدیوی اینترو + اسپرایت‌های UI + پس‌زمینه‌های محو + چک‌لیست تولید.
- `assets/_inbox/` + `tools/integrate-media.mjs` — تشخیص خودکار نام فایل، جایگذاری در مسیر، مانیفست `assets/images/manifest.json`.
- `js/media-assets.js` — ران‌تایم مسیرها را از مانیفست حل می‌کند؛ **تعویض تصاویر بدون هیچ تغییر کد** (هر فرمتی).
- هوک‌شده در tour.js (اتاق/نقشه/اسلایدشو گردش مجازی).

## ۹) تعمیرات و بهبودهای زیرساختی

- پایدارسازی کودکان/گزارش‌ها در `data/children.json` (قبلاً با ری‌استارت از بین می‌رفتند)
- API client: متدهای planner/parent-messages
- تب «🗓 برنامه‌ریزی» در پنل برای همه‌ی نقش‌ها
- حالت خالی SVG در پیام‌ها/جستجو/محتوای اتاق
- ارقام فارسی شمارنده‌ها
